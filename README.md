# La Francisca · boceto de sitio web

Propuesta visual inicial para conversar sobre la futura web de la panadería y cafetería La Francisca.

## Vista previa

La página principal es `index.html`. Las imágenes del negocio están en `assets/`.

## Contenido provisional

- Los textos, promociones, productos y precios son ilustrativos y quedan sujetos a confirmación.
- Instagram, X/Twitter y Facebook aparecen como iconos de muestra, sin enlaces asociados.
- El botón flotante de WhatsApp es visual; se configurará cuando se confirme el número y el enlace del negocio.
- Las imágenes de productos y las diapositivas secundarias son fotos de referencia y podrán reemplazarse por fotos del local.
